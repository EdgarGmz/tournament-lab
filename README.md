# Tournament Lab

Tournament Lab es una aplicación web diseñada para facilitar la creación y gestión de torneos.

## Descripción

El proyecto se divide en dos componentes principales:

*   **Backend:** Una API RESTful desarrollada con .NET y C#, responsable de la lógica de negocio y la persistencia de datos.
*   **Frontend:** Una aplicación de una sola página (SPA) desarrollada con React, que consume la API del backend para proporcionar una interfaz de usuario interactiva.

## Estructura del Proyecto

*   `back/`: Contiene el código fuente y la configuración del backend. Para más detalles, consulta el [README del backend](./back/README.md).
*   `front/`: Contiene el código fuente y la configuración del frontend. Para más detalles, consulta el [README del frontend](./front/README.md).
*   `docs/`: Contiene documentación adicional del proyecto, como diagramas de arquitectura y requerimientos.
