# 🎮 Tournament Lab - Backend

Este es el backend de la aplicación **Tournament Lab**, un sistema para gestionar torneos de videojuegos y TCGs. Desarrollado con **Node.js**, **Express** y **MongoDB**.

---

## 🧰 Tecnologías utilizadas

- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)
- [MongoDB](https://www.mongodb.com/)
- [Mongoose](https://mongoosejs.com/)
- [Dotenv](https://www.npmjs.com/package/dotenv)
- [Cors](https://www.npmjs.com/package/cors)

---

## 🚀 Requisitos previos

- Node.js y npm instalados
- MongoDB Atlas (o local) con una URI válida
