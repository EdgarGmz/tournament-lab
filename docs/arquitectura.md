# Arquitectura del Proyecto - Tournament Lab

## Descripción general
Tournament Lab es una aplicación fullstack para gestionar torneos de videojuegos y TCGs.

## Estilo Arquitectónico
Cliente-Servidor + MVC  
Frontend: React  
Backend: Node.js + Express  
Base de datos: MongoDB

## Capas
1. **Presentación**: React (Create React App)
2. **Negocio**: Node.js con controladores Express
3. **Persistencia**: MongoDB
